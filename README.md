## What is this repository?

This is a fork of the Awesome-Selfhosted HTML site. The `gh-pages` branch contains generated website files, including HTML pages, search assets, static resources, and category/tag pages. It is primarily a published site artifact rather than the canonical source for the upstream Awesome-Selfhosted project.

For the authoritative project description, contribution guidance, source data, and current licensing terms, consult the upstream repository and the license/notice files distributed with the relevant material.

## Viewing the site
