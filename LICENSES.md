# License Scope and Reuse Guide

## Repository status

This repository is a public fork of the generated HTML publication at [awesome-selfhosted/awesome-selfhosted-html](https://github.com/awesome-selfhosted/awesome-selfhosted-html). The upstream HTML repository's GitHub metadata does not identify a repository-wide SPDX licence, and its generated branch does not provide a root-level licence file. Therefore this fork does **not** declare a single licence for every file.

## Confirmed licence statement

The [Awesome-Selfhosted catalogue README](https://github.com/awesome-selfhosted/awesome-selfhosted) identifies the catalogue/list as licensed under **Creative Commons Attribution-ShareAlike 3.0 Unported (CC BY-SA 3.0)**. See [the licence terms](https://creativecommons.org/licenses/by-sa/3.0/) and the upstream catalogue licence file linked from that project.

This is a scoped statement about the catalogue/list. It is not proof that the same licence applies to every generated HTML page, Sphinx/Furo file, JavaScript bundle, source map, stylesheet, icon, logo, favicon, font, or other third-party asset.

## How to determine the licence for a file

1. Check the file's own header, embedded notice, or adjacent `*.LICENSE.txt` file.
2. Trace generated files to the upstream source and build configuration: [HTML project](https://github.com/awesome-selfhosted/awesome-selfhosted-html) and [data project](https://github.com/awesome-selfhosted/awesome-selfhosted-data).
3. Check the applicable package or upstream project's licence and copyright notices for bundled libraries and theme assets.
4. Preserve all notices and required attribution when copying or redistributing.
5. If evidence is inconclusive, mark the file **unverified** and seek rights-holder clarification; do not guess or assign a licence.

## No blanket relicensing

No top-level `LICENSE` has been added by this fork because a complete rights review has not established a single licence that can safely cover the entire generated tree. Do not use this document as a substitute for a file-specific licence. Do not claim inherited material as original, imply upstream endorsement, or imply that JAHIDS.AI owns upstream or third-party work.
