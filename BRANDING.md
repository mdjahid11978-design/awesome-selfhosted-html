# Branding and Name Usage

## Canonical maintainer identity

- **Canonical platform name:** JAHIDS.AI Sovereign AI Platform
- **Short brand name:** JAHIDS.AI
- **Attribution line:** Built by Jahid
- **Domain:** https://jahids.ai

Use the canonical platform name in this fork's maintainer-owned documentation and engineering alignment records. Use the short name where space is limited.

## Respect the upstream project identity

This repository is a fork of the Awesome-Selfhosted generated HTML publication. Its catalogue, site content, third-party names, logos, icons, fonts, and other assets must not be rebranded as original JAHIDS.AI work.

Keep the published catalogue's identity and attribution intact. Do not imply that Awesome-Selfhosted endorses, operates, or is owned by JAHIDS.AI. Do not replace upstream logos, favicons, footer credits, or embedded notices unless the relevant rights and project rules have been reviewed and the change is appropriate.

## Allowed use

- Identify this repository as a **JAHIDS.AI-maintained fork** in maintainer-owned documentation.
- Use **JAHIDS.AI Sovereign AI Platform** as the canonical platform name in this repository's own governance and alignment documentation.
- Use **Built by Jahid** as maintainer attribution for original documentation written for this fork.

## Rights and provenance

Branding does not create ownership or licence rights. Preserve all upstream and third-party notices. The licence for catalogue/list content does not automatically apply to every generated page or bundled asset. Refer to [LICENSES.md](./LICENSES.md), [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md), and [ASSET_PROVENANCE.md](./ASSET_PROVENANCE.md).
